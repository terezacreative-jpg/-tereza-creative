TEREZA CREATIVE – web zdarma

OBSAH
- index.html: celý responzivní web v jednom souboru
- Žádné placené knihovny ani externí fonty

JAK SI WEB PROHLÉDNOUT
1. Rozbal ZIP.
2. Otevři index.html v prohlížeči.

PŘED ZVEŘEJNĚNÍM
1. Otevři index.html v textovém editoru.
2. Najdi řádek const CONTACT_EMAIL='' a vlož mezi apostrofy svůj skutečný e-mail.
3. Formulář pak otevře e-mailovou aplikaci uživatele. Pro odesílání přímo z webu bez e-mailové aplikace bude potřeba formulářová služba nebo backend.
4. Doplň své kontakty a odkazy na sociální sítě.
5. Ukázky portfolia jsou pouze grafické koncepty. Nahraď je vlastními videi/fotkami a používej jen pravdivé reference.

BEZPLATNÉ ZVEŘEJNĚNÍ
Web lze publikovat na bezplatném statickém hostingu, například GitHub Pages nebo Netlify free tier. Dostupnost a podmínky služeb se mohou měnit. Vlastní doména bývá placená. Tento balíček web sám nenahrává na internet.
